Examen de HTML y PHP

1. ¿Qué etiqueta se utiliza para crear un enlace?

<link> <a> <url>

2. ¿Qué etiqueta se utiliza para crear un formulario?

<form> <input> <button>

3. ¿Qué método se utiliza para enviar datos de un formulario sin mostrarlos en la URL?

GET POST SEND

4. ¿Qué variable utiliza PHP para recibir datos enviados mediante POST?

$_GET $_POST $_FORM

5. ¿Qué etiqueta se utiliza para crear una lista desplegable?

<select> <list> <dropdown>

6. ¿Qué etiqueta se utiliza para crear una opción dentro de un select?

<choice> <option> <select>

7. ¿Qué atributo identifica el dato que se envía al servidor?

id name class

8. ¿Qué etiqueta se utiliza para crear una casilla de selección?

<checkbox> <input type="checkbox"> <check>

9. ¿Qué lenguaje se ejecuta en el servidor?

PHP HTML CSS

10. ¿Qué etiqueta se utiliza para crear un botón?

<button> <boton> <press>
